# Touba 1.2.0

## Executive Summary

This candidate carries the four mandatory showcase corrections: prepared
resources, strict configuration, effect-journal migration diagnostics and
host-controlled compensation. Local qualification precedes public distribution.

## Added

- JavaScript and Python SDK entry points to create and resume compensations.
- Explicit host activation of declared triggers, with limits that can be lowered.

## Changed

- Prepared projects carry resource-file references and fingerprints across CLI,
  SDK and server execution. Each call receives its permitted resource projection.
- Unknown manifest and host-configuration fields produce actionable diagnostics.

## Fixed

- Resource bindings reach each declared module, including after an approval pause.
- Effect-journal errors identify the explicit JSON-to-SQLite preview/apply path.
- SDK 1.2.0 is admitted by strict supply-chain validation alongside 1.0.0 and 1.1.0.
- The editor bundle includes the shared resource and manifest validation contracts.

## Security And Governance

Compensations require an explicit host authority adapter. Checks precede journal
lookup, resumption and dispatch. Durable records and leases protect competing
requests and replay. Resource bindings cannot enlarge the source memory grants;
changed bindings invalidate a pending approval's recorded contract.

## Breaking Changes

Misspelled or unsupported configuration keys previously ignored are now refused.
Correct these fields before preparing or executing a project. Language syntax,
existing valid bindings and resource permissions retain their meaning.

## Migration

1. Preserve project data and finish or reconcile pending operations with their
   original build and approved contract.
2. Install the candidate and explicitly update the SDK in each test project.
3. Prepare the project again and address reported configuration errors.
4. For an existing JSON effect journal, use the documented migration preview and
   apply commands to create a new `.effect-journal.sqlite` store. Retain the JSON
   backup and associated checkpoint and approval stores.

Installation does not update project dependencies, migrate their state or resume
approvals. Financial and other business effects remain the application's domain.

## Validation Evidence

The targeted suites cover resources through CLI, HTTP and both SDKs; authority
refusals; approval drift and replay; strict configuration; and compensation
creation/resumption through installed SDK archives, including competing processes.
The Mac candidate also undergoes archive installation and native editor tests.
Public delivery still requires qualification of its exact multi-platform builds.

## Known Limits

This local candidate is intended for developer retesting. It is not an update to
the public download catalogue. Compensation handlers and their business behavior
are supplied by the application; Touba controls their admission and execution.
