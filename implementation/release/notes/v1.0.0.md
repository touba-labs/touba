# Touba 1.0.0

## Executive Summary

`1.0.0` is the target of the first official public Touba release. This entry
records the candidate being qualified, not a publication announcement.

## Added

The distribution includes the compiler, governed runtime, CLI, and paired
JavaScript and Python SDKs. Native archives and graphical installers target
macOS Apple Silicon, macOS Intel, Linux x64 and Windows x64.

## Changed

The compiler, runtime, CLI and both SDKs share the product version `1.0.0`.
Business packages retain their own versions. Installed Python and JavaScript
hosts can resolve the Windows toolchain without executing a command shell.

## Fixed

Installed-SDK checks exercise default command discovery, both JavaScript
engine modes, Python execution and decision history without development paths.
Release validation checks Rust and Python metadata as well as JavaScript.

## Security And Governance

Authority, approval, scope, budget and trace checks remain runtime boundaries.
Qualification of required OS confinement is separate from ordinary Windows
execution. Security review and publisher signing remain publication gates.

## Breaking Changes

There is no earlier supported public release. Private prototype builds are
not a compatibility baseline for this first public distribution.

## Migration

Private testers should preserve their projects and data, install the qualified
candidate, then refresh project SDKs with `touba sdk install javascript` or
`touba sdk install python`. Check the actual installed build with
`touba version --json` and project prerequisites with `touba doctor --json`.

## Validation Evidence

The local V1 suite, installed-SDK checks, native installer workflow and
`release-readiness` report are separate evidence sources. A result applies to
its recorded source snapshot and asset checksum. Cross-platform execution,
human installation sessions and industrial qualification must be recorded
before publication; a successful build alone does not satisfy these gates.

## Known Limits

This candidate is not published. Final native qualification, publisher
signatures, dependency review, human checks and production restore validation
must be resolved before the release index can mark it published. Download
links remain disabled until their exact assets are available and qualified.
