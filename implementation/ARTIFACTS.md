# Generated Artifacts

This repository keeps generated artifacts out of source control unless a file is
explicitly documented as a fixture.

## Ignored Regenerable Outputs

The following paths are local outputs and must not be committed:

| Path | Producer | Policy |
| --- | --- | --- |
| `dist/` | package and release scripts | ignored, regenerated from source |
| `build/` | local build scripts | ignored, regenerated from source |
| `coverage/` | test coverage tools | ignored, regenerated from tests |
| `.docusaurus/` | Docusaurus | ignored, regenerated by the docs site |
| `.pnpm-store/` | pnpm local store | ignored cache, never part of a release |
| `.vscode-test/` | VS Code integration tests | ignored cache, may be deleted safely |
| `.toolchains/` | local downloaded toolchains | ignored cache, not source of truth |
| `target/` | Cargo | ignored build output |
| `vsix-staging/` | VSIX packaging | ignored staging directory |
| `*.vsix`, `*.tgz` | package scripts | ignored release candidates unless explicitly published elsewhere |

Generated fixtures are different: files under `tests/`, `grammar/.../examples/`
or documented fixture directories may be tracked when they are part of a
validation corpus.

## Release Rule

Before preparing a release candidate, regenerate packages from a clean checkout.
Do not promote an old `dist/`, `.vscode-test/`, `.pnpm-store` or local archive as
evidence of the current source tree.

## Cleanup

Recreate the Core artifacts from this repository’s root.

```sh
pnpm --dir implementation package:touba-toolchain
pnpm --dir implementation package:touba-release-macos
```

Build an editor archive with `pnpm package:local` from the Touba IDE repository.
