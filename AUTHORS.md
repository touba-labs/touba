## Citing Touba

GitHub's **Cite this repository** button uses [CITATION.cff](CITATION.cff).
The same reference in BibTeX:

```bibtex
@software{lo_alaoui_dessureault_touba_2026,
  author  = {Lo, Khadim and Alaoui Ismaili, Soukaina and Dessureault, Jean-S{\'e}bastien},
  title   = {Touba: A Programming Language and Runtime for Governed Agentic Systems},
  year    = {2026},
  url     = {https://github.com/touba-labs/touba},
  license = {Apache-2.0}
}
```

The papers on Probabilistic Agentic Programming and Touba, with their status,
are listed on the [research page](https://toubalang.org/recherche/).
