# Security

Security reports are taken seriously.

## Reporting A Vulnerability

Do not open a public issue for exploitable vulnerabilities, leaked secrets,
credential exposure, supply-chain compromise or bypasses of authority,
validation or traceability controls.

Use one of these channels:

- GitHub Security Advisories, when enabled for the repository;
- Touba Labs security contact: [contact@touba-labs.com](mailto:contact@touba-labs.com).

Include:

- affected repository and commit or version;
- impact and affected capability;
- reproduction steps or proof of concept;
- logs, traces or relevant files when safe to share;
- whether the issue is already public.

## Coordinated Disclosure

Please allow time for investigation and remediation before public disclosure.
The project will prioritize fixes that affect execution authority, tool access,
secrets, memory boundaries, package integrity, trace integrity and user approval
flows.
