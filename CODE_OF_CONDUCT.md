# Code Of Conduct

This project expects professional, respectful and precise collaboration.

## Expected Behavior

- Be respectful and direct.
- Critique ideas and code, not people.
- Use clear technical arguments.
- Assume responsibility for the changes you submit.
- Keep discussions focused on the repository scope.
- Respect security and disclosure processes.

## Unacceptable Behavior

- Harassment, threats or discriminatory language.
- Personal attacks or repeated bad-faith disruption.
- Publishing private information without permission.
- Sharing secrets, credentials or exploit details in public issues.
- Misrepresenting project status, authorship, security or compliance.

## Enforcement

Maintainers may moderate, edit or remove issues, pull requests, comments and
other contributions that violate this code of conduct. Serious or repeated
violations can lead to blocked participation.
